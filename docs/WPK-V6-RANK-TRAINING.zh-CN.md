## 训练链与人工复核

- 只加载第一段录像的旧归一化图，逐文件验证原标注中的SHA-256；第二段不参与点数训练。
- 从212个带标签的点数槽位提取91种去重字形，生成只含字形的私有目检拼版。
- Codex逐张目检，明确批准86种，拒绝5种明显裁切/蓝色覆盖/纯红色块污染的字形。
  拒绝记录为r020、r044、r045、r053、r058；没有沿用旧标签把不可辨字形当正确输入。
- 获准字形关联207个旧槽位、37张图、18个旧hand_id。**18不是已核实完整手数**。
  所有13个点数均覆盖，每类4–9种字形；86种是很小的训练集，不代表广泛场景覆盖。
- 当前只做按录像分区：session_001训练，session_002开发/新片段检查。
  旧完整手牌边界和花色模型的历史训练重叠尚未核实，不宣称全模型手牌级独立验收。

特征使用v5亮度归一化和已修复的配准。每种原字形附加24个尺寸、亮度与同字形合成融合样本，
总计2150个训练输入。**不是2150个独立实拍样本，也不是从连续实拍重建的训练特征**。
下一步仍需补真实连续融合特征、换手/动画负样本和更广泛的真实牌局。

花色头沿用原权重，10个数组逐一确认未改变。

训练数组、导出权重和本机实际运行依赖清单。

模型、阈值与标定文件绑定哈希；只在离线评估中应用，现用生产配置不改。

## 第三批新片段

顺序提取14500–17050，共27张图。推理前逐张查看并冻结8个检查点：
14800、15100、15400、15700、16000、16300、16600、16900。
14500延续上一批QhTc手牌，只作预热，不计入新检查点。
15100/16300为已弃牌；15700为零筹码、仍持亮牌的all-in，不因没有按钮而归为旁观。
16600有缩放中的按钮遮挡底牌，仍要求完整识别，不以“困难”放宽覆盖门槛。

新段未用于选择点数权重或0.50门槛，但旧花色头训练重叠仍不明确。
连续回放14500–16900，共2401帧，在冻结的8个检查点评分。**首测通过本批卡面候选门槛**：

| 指标 | 第三批首测 |
|---|---:|
| 底牌正确接受 / 正槽位 | 15/16 |
| 底牌拒答 / 错误接受 | 1/0 |
| 要求完整的在局底牌节点 | 6/6 |
| 公共牌正确接受 / 正槽位 | 20/20 |
| 完整公共牌节点 | 8/8 |
| 空公共牌槽位正确保持为空 | 20/20 |

唯一拒答位于15100已弃牌的灰暗底牌；没有放宽16600动画遮挡节点的要求。
这些是8个检查点的结果，不是2401帧全部具备人工真值。
本批没有“空底牌”检查点，负样本覆盖仍不足；后续要补空底牌、发牌、换手和持续过渡。
此结果只证明这组离线候选检查通过，不证明整段状态有效、牌理/策略正确或盈利。
旧花色头仍非全模型独立，样本也不足以证明极低的长期误报率，因此生产不放行。
