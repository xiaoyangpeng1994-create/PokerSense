# 三人河牌响应模型与动作EV：V1

2026-09-13。用户授权继续策略模块，先处理6–8人桌中三人进入河牌、初始单底池的人工假设局面。新增实现不依赖视觉输入，不修改既有终结跟注模块或冻结文件。

**工程目标：在明确范围、响应权重、价格效应与有限动作空间内，比较每个声明动作的条件EV，并给出完整的后续决策依据。** 输出不是GTO、不代表真实对手模型或盈利证明，也不接入生产Advice。

## 输入与当前边界

- `seats`是河牌开始时的状态：6/7/8名已入局者，3名ACTIVE，其余FOLDED。本街投入从0开始，3名active的之前累计投入相同，其他人的贡献不超过该水平，避免既有边池或未结清超额款。
- 三名active的筹码严格大于最大声明下注目标，因此本版不会碰到all-in/short-call/sidepot边界。已有terminal_multiway模块保留，不在本轮强行拼接。
- `action_order`显式给出3名active的顺时针顺序。`history`从河牌开始重放到Hero；不是用当前剩余筹码再扣一遍历史投入。
- `range_start`必须是`river_start`。历史上对手的动作会对联合范围条件化一次；当前节点范围不能冒充起始范围后再次条件化。
- 五张公共牌、Hero两张牌已知，对手是手工假设的具体组合与权重，ESS/confidence=0。起始独立权重经已知牌、对手间碰牌及公开动作约束条件化；未建立其他已弃牌玩家的经验范围模型。
- 首次最小下注使用配置的big_blind；后续最小加注由上一次完整加注增量推导。AA具体房间若有其他河牌最小额规则，不能未经扩展直接套用。
- `aggression_targets`是预先声明、递增的本街总投入目标，不是追加金额。首次bet和后续raise均计入`max_aggressions`，上限3。该上限和尺寸网格是模型动作抽象，不是完整NLHE规则，不是计算预算截叶。
- 费用采用已有精确配置，未知额外费用拒绝；平分采用fractional模型，不处理实体奇数筹码分配、ICM或完整历史合法性证明。

## 响应模型

每名对手只能使用其自身两张牌与公开公共牌形成的牌型类别、公开可行动作和公开价格。实现不接受任意callback，也不会把Hero或另一位对手的具体牌传给策略模型。

每个节点的计算为：

1. 按自身牌型类别选择基础动作权重；无类别覆盖时使用默认表。
2. 计算公开价格`to_call / (current_pot + to_call)`；免费行动为0。此前其他人已投入的金额进入current_pot。
3. 选择第一档`upper_ratio >= price`的价格乘数；档位必须递增且最后为1。
4. 基础权重乘价格因子后，在当前合法动作中精确归一化。基础缺失动作权重为0，缺失乘数为1；没有合法正概率响应时拒绝整次分析。

精确尺寸key如`bet:20`优先于`bet`。通用bet/raise权重作用于每个匹配的具体尺寸，因此改变网格也会改变归一化结果；这些是行为权重，不是无需归一化的观察频率。

预置tight、loose_passive、aggressive都是**未训练的演示参数**，牌型类别很粗，不能当成真实玩家画像。示例v2还声明了价格档位和乘数。

## 公共信息集与EV

每个公开行动历史保留整组联合牌假设及其后验。对手的一个公开动作形成分支时，先按各假设下的动作概率更新后验，再计算子节点。

Hero在该公开信息集的整组后验上比较动作EV并统一选择。禁止“针对每份隐藏牌分别选最优动作，再取平均”的策略融合/透视错误。已弃牌对手的潜在手牌与弃牌概率不会从联合假设中删除，仍可通过碰牌影响另一位对手的后验。

过牌、跟注、弃牌、下注、加注按顺序推进；加注重新打开后续待行动队列。Hero弃牌后，其他玩家仍按模型继续完成分支。终局重建资金、未跟注返还及配置抽水，Hero EV只减根节点之后的新投入，既投筹码不重复扣除。

`hero_policy`保留各公开历史下的后验、备选动作EV与所选动作；`joint_hypotheses`与后验索引对应。`root_context`给出当前pot、bet、Hero本街已投、to-call、pending与公开价格；每个动作都有`additional_cost`。

## 实际示例

文件：`configs/strategy/examples/threeway-river-response-manual.json`。

6人桌、3人进入河牌；初始pot90。对手1先下注20、对手2跟注20，当前pot130，Hero需要跟20。给定两份手工起始范围和示例响应模型后，实际计算得到：

| 动作 | 本次追加 | 条件净EV约值 |
| --- | ---: | ---: |
| FOLD | 0 | 0 |
| CALL | 20 | 35.8522 |
| RAISE到40 | 40 | 35.0634 |
| RAISE到80 | 80 | 35.6915 |

在选定模型下CALL最高，但与次优只差约0.1607筹码。9组对手风格配对、16组响应权重±10%扰动和8组范围权重±10%扰动均实际运行，示例三类检查均标为`MODEL_SENSITIVE`。不能把该CALL说成稳定或已验证实战建议。

每个敏感性变体都从相同river-start范围与历史重新条件化，不复用基线后验。局部范围测试只改已声明组合的权重，没有涵盖遗漏组合；最多64个范围扰动，超限明确INCOMPLETE，不静默抽几个点冒充完整检查。任何请求的敏感性检查未完成，CLI退出码为2，即使基线自身完成。

`--output`保存包含所有后续Hero政策和模型参数的完整JSON，目标必须是新文件。默认摘要保留manual/NOT_GTO/非实证限定、每个style对应的seat，以及strategy/advice均false，避免只看见动作数字。

默认每次分析最多128个联合牌假设、20,000节点；参数有显式上限。任一预算耗尽都返回BLOCKED，根动作EV与最佳动作为空，不把未计算叶子改成摊牌收益。节点预算不是已验证的墙钟deadline，亦不表示复杂输入能达到实时要求。
