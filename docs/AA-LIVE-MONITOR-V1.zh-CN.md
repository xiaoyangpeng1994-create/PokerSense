# AA 八座观察工具 V1

新增 AA 专用入口，将现有 AA8 识别器连接到本地八座页面。显示底牌、公共牌、底池、筹码、投入、参与候选、行动者、字样与预览；这些仍是开发候选，不是完整合法牌局或可靠策略建议。本版本没有开发 WPK。

## 启动

源码运行需要 Python 3.12、项目 desktop 依赖、完整源码目录（包含 tools）和本机已授权的 AA8 模型／模板。现有 factory JSON 的九项路径字段可用，使用本工作目录的布局与 heads 路径；未知字段拒绝。先检查文件与八座 Hero4 布局，点击开始才加载识别模型。

```powershell
$env:PYTHONPATH='src;.'
$env:PYTHONUTF8='1'
python -m poker_engine.desktop.aa_server --profile '<本机AA8工厂配置.json>' --port 8771 --open-browser
```

无 `--allow-capture` 时采集卡入口关闭。设备可用且用户准备好本次验证时，添加该参数后在页面明确选择设备编号、MSMF/DirectShow，再点击开始。当前请求1920×1080、30FPS，按[711,0,1209,1080]裁剪为498×1080；其他画面几何拒绝。不录制音视频，不操作客户端。

开发验证可另加 `--replay-pool '<已登记开发PNG目录>' --replay-first 1470 --replay-last 1750`。只接受同一 audit、连续且 role=development 的登记帧；逐图检查路径和SHA。浏览器不能传任意文件路径。开发回放与现场来源在页面区分。

## 行为与限制

- 多页面共享一个识别会话；明确开始／停止，不因打开页面自动开设备。
- 采集线程持续读取，保留一个最新帧，识别消费时不会排队处理全部旧帧。原采集序号与处理序号分开；采样不能证明完整动作覆盖。
- 结束、停止、异常、过期立即清空公开字段与预览；迟到结果不得写回。旧工作线程退出前不能启动新会话。
- 驱动读操作若阻塞，状态保持STOPPING；当前没有进程级强制终止机制。实机驱动、断开与恢复仍待验证。
- 模型重连／时间间断时重置临时状态，保留冻结模型；不注入人工手边界或修改canonical资格。
- 当前初始化仍依赖外部私有开发参考文件；预检 ready 仅表示资源存在与配置结构可读，不是模型准确率或完整资源包验封。
- V3字样补充可通过profile的glyph_supplement提供fold/muck/all_in三份哈希绑定引用。当前本机基础profile未启用该可选补充，接续应在开发回归后明确启用，不能假称所有最新模板已部署。
- 页面显示的是处理耗时，不是手机画面到界面的端到端延迟。预览与字段独立更新，不宣称精确同帧同步。
- 完整AA状态、强多人策略和高盈利验证尚未完成。未放开策略门禁。

## 独立打包

```powershell
python -m PyInstaller packaging/aa_live.spec --distpath '<输出目录>' --workpath '<构建目录>' --noconfirm
```

`PokerSense-AA.exe --profile '<配置路径>' ...` 使用独立AA入口，参数解析进入可执行程序。打包路径包含src和显式依赖的tools模块、AA页面；模型／模板仍外置。没有改变旧桌面入口或旧安装包版本，也没有发布Release。
