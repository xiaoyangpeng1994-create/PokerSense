# AA8 V2 下注几何拒识修复

新增`tools/aa8_wagergeometry_v2.py`，不改V1、模型、置信度门槛或币标0.85门槛。

## 两个真实原因

1320的1号2不是识别器单纯“看不懂2”：旧17像素币标条带包含一个独立4×1
按钮边缘亮斑，位于条带第16行，触及下边界，所以报clipped_wager_digits。
真正数字是8×12连通组件，没有越界；左/右/上均不是此次裁切失败边界。
仅把条带变高会把该亮斑计入数字，造成后续classifier ambiguous。
新候选在ROI内最多上下3像素检查，按数字行连通组件定位；远低于数字行的
孤立薄边缘不扩大数字裁切，靠近基线的小点保留为标点歧义并拒识，不能删小数点。

2070 Hero下注ROI的60个亮像素实际在全图x353–369、y833–837，来自灰色预选
按钮边缘，不是玩家名。Hero下注币标在所有已核对标签帧中占y814–830。
候选ROI改为(292,808,78,24)，完整覆盖币标与数字并在y832结束，排除该按钮。
此范围仍需其他开发手和独立资料验证，不能当作所有尺寸布局的既成事实。
