## 可撤销

如果要暂停本次新增规则，在管理员PowerShell中执行：

```powershell
Disable-NetFirewallRule -Name 'PokerSense-LD9-Block-External-Debug-TCP-v1'
```

重新启用可用`Enable-NetFirewallRule`配合同一规则名。不要因此关闭整个Windows防火墙。
