# AA Poker 客户端环境参考

状态：**结论已于 2026-09-09 独立查证后推翻重写**。本文仅记录 PokerSense AA 轨道的
环境选型依据与风险，不是 AA 官方规则，也不是策略建议，不含任何推广/邀请内容。

> 红线提醒：PokerSense 是训练陪练工具，绝不自动点击/下注/控制客户端。

## ⚠️ 核心结论：不要用模拟器跑 AA

**AA 绿盾风控系统明确禁止模拟器 / 虚拟机 / 远程桌面环境。**

独立查证来源一（中扑网 dzpknews.com，2026-01-10，《深挖 AA POKER 绿盾Plus 的"端到端"黑科技》）原文：

> "设备/环境封堵与证据链：**禁止远程桌面/虚拟机/模拟器等环境（要求客户端"原生硬盘运行"）**；
> 反实时外援/屏幕共享是反作弊的关键一环。结合窗口焦点/快捷键节拍、多开/跨屏特征，做环境风险分层。"

> "6.设备/环境与风控：**触发远程桌面、模拟器、虚拟机等受限环境**；频繁异常的前后台切换/
> 窗口焦点模式等。**与可疑第三方软件的同机指纹/网络指纹关联。**"

独立查证来源二（代理商页面 hnskn.com 列出绿盾功能清单）：

```
NO AI  01 禁止AI 2.0
MNQ    02 禁止模拟器      ← 明确条目
CD     03 禁止虫洞
MAN    04 人机检测
REAL   05 活体检测
SJ     06 禁止辅助
```

**推论：用户此前收到的「PC 端推荐雷电模拟器 9.0 / AA 支持雷电」属代理分发话术，
与 AA 官方风控政策直接矛盾。按该话术用模拟器跑 AA = 高风险封号。此结论已覆盖本文先前版本。**

## 正确路径：用 AA 官方 Windows 原生客户端

AA 本身提供**原生 Windows / Mac 桌面客户端**（非模拟器）：

- 官方/品牌站体系（`aapoker.games`、`aapoker.tw`）为同一 AA POKER 品牌（TLPT、GLI 认证、
  绿盾风控、蘑菇模式 / 暴击底池 / 保险模式——与本项目 `AA-SPECIAL-MODES-EVIDENCE` 吻合）。
- 多个下载入口明确列出 PC 端：Windows 版、macOS 版（`aapk.ggpoker360.com`、`aapkcn.com` 等）。
- ToS（`aaglobal.io`）亦定义 "PC Software" = 可从 `www.aapoker.com` 下载到个人电脑的软件。

**用原生 Windows 客户端 = 不触发「禁止模拟器」条款，且无需雷电、无需采集卡、无需 ADB。**

## 对本项目的采集方式影响（好消息）

Windows 原生客户端意味着可直接用仓库已有的 `mss_backend`（Windows 窗口捕获：
DPI 感知 + HWND 查找 + GetClientRect + mss grab）取帧。

| 方案 | 是否触发「禁模拟器」 | 采集方式 |
| --- | --- | --- |
| 雷电 + ADB 抓帧 | **是（高封号风险）** | `--source adb` |
| 雷电 + 采集卡 | **是（仍是模拟器环境）** | capture-card（且 AA 标定未做） |
| **Windows 原生客户端 + 窗口捕获** | **否** | `mss_backend`（代码已有，需 AA 标定） |
| 真机 + 采集卡 | 否 | capture-card（AA 标定未做） |

结论：**AA 轨道应改走「Windows 原生客户端 + mss 窗口捕获」，放弃模拟器路线。**

## ⚠️ 更深一层的风险（采集方式无法规避，需 owner 决策）

绿盾的首要打击目标就是 **RTA（Real-Time Assistance，实时外部辅助）** 与**屏幕共享**：

- 原文："反实时外援/屏幕共享是反作弊的关键一环"、"**严禁任何形式的实时外部辅助**"。
- 检测维度含行为学对齐度、决策熵、时序学（思考时长/恒定延迟）、牌谱序列"解题者相似度评分"、
  跨场景策略指纹一致性，以及**同机第三方软件指纹关联**。
- **PokerSense 虽不自动下注（硬红线），但其"实时读屏 + 给建议"形态在平台风控定义下即属 RTA。**

因此：即便改用原生 Windows 客户端，**PokerSense 对 AA 这类强 RTA 检测平台仍处于被打击范围内**。
此项非技术可规避，属产品/合规决策，须由 owner 拍板（是否继续推进 AA 轨道、或仅做离线复盘）。
