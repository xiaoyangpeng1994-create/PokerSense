## 需要从录像继续提取的保险合同字段

| 字段 | 为什么必须单独记录 |
|---|---|
| 生效街道与覆盖到哪张牌 | 只保下一张牌，和覆盖剩余整段 runout 不是同一个事件 |
| 主池/边池及保险购买者 | 不能对没有资格赢的池计算保障 |
| 承保 outs 与是否包含平局 | 玩家输牌概率不一定等于保险触发概率；可能只选择部分outs |
| 保费、保额、赔率 | 赔率是毛赔付还是净赔付，是否包含本金，必须明确 |
| 保费扣除时点与来源 | 预先扣、获胜时扣、钱包扣或筹码余额扣会改变账本 |
| 赔付时点与来源 | 保险池付款不能混成牌桌底池赢钱 |
| 自动投保与人工选择 | 先从画面记录，软件不自动购买或操作客户端 |
| 取整、封顶与附加费 | 不能让误差被错误归因于识别或策略 |

## 数学与程序处理原则

保险不改变固定牌面下的摊牌胜率；它改变资金结果分布，是否改善 EV 要由真实合同决定。
如果保费C无条件扣除、触发事件概率为p、事件发生时收到毛赔付B，则保险增量EV为 `p×B−C`。
只有明确这些前提才能使用该公式；若保费仅在某一结果下收取、B为净赔付或包含本金，必须重新写出分支现金流。
