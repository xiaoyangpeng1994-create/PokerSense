# WPK 本人余额位置选择 v1

日期：2026-09-08。离线位置选择与当前画面读数组合完成；生产/参与状态/真实筹码语义未放行。

## 已完成的组件

`tools/wpk_hero_balance_layout.py`识别余额胶囊两端的边框，比较底部约y1056和上方约y937
两处正证据。特征不包含中间的数字，不依赖“没有按钮/底牌”的反向推断。
同帧两处均过门槛则CONFLICT，两处均不足则UNKNOWN；不按较高分强选一个位置。

边缘使用Canny30/60、对称像素F1，门槛0.70为开发工程选择，未作独立生产标定。
模板来源为f11000底部胶囊、f10700上方胶囊。仅支持已审阅498×1080画布；尺寸不符拒答。

选择后使用v1筹码裁剪尺寸及原生产数字识别器/原金额门槛读取当前画面。
无法选位置时不调用数字识别，不保留以前的值。返回始终带
`participation=UNKNOWN`、`usable_stack_verified=false`、`production_valid=false`。
所以“选择上方位置”不等于已经证明本人在等待、入座成功或有可参与下注的筹码。
