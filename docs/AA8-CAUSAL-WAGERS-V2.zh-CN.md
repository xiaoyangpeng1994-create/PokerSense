# AA8 V2 自动本轮投入候选

新增`tools/aa8_live_wagers_v2.py`，不改变冻结V1或策略层。
接口：`CausalWagersV2.observe(prepared_row, adapter, partition_observation)`。
adapter必须先消费同一个当前帧。输入不含人工“此前无动作”等布尔标注。

## 自动上下文与有限状态

- 当前中央金额读数缺失时仅暂停公开输出，保留私有候选等待新画面核对；
  不把一次OCR缺失当成实际收池。数值确实改变、断帧、换街、保险等仍失效。
- 未知下注ROI和未知标题不计作正向金额矛盾；不因未知持续12帧就摧毁私有
  历史。公开值仍为UNKNOWN，恢复时仍须当前中央/标题/下注与动作账全部一致。
  明确可见金额矛盾仍有12帧确认窗口，超时清理；未知时间不充当矛盾时间。
- 从适配器观察epoch、正向新街、全部已确认/待确认动作与现金变化历史推导
  初值许可；不能因为当前界面空了就忽略同一街更早动作。
- 初始UNANCHORED发牌的preflop保持UNKNOWN；有多座扣款与发牌证据的新手
  可以尝试preflop初值，正向新公共牌允许建立新街初值。
- 当前明确EMPTY/WAITING才是NA；当前行动者、无模式阻断与完整分区证据齐全，
  相邻两帧满足标题=中央+可见下注后，才初始化条件金额。
- 此后仅把已验证到对应视觉现金的动作debit加入一次。绝对下注标签只用于
  对照，不再加一次，因此没有“标签改变加一次、动作再加一次”的重复问题。
- 标题、中央或可见标签与内部候选账不一致时，公开输出UNKNOWN；最多等待12帧
  供滞后的动作标记确认，仍不一致则失效。这不是在等待中继续发布旧账。
- 断帧、模式阻断、保险、收筹导致中央改变均作废初值。未知ROI也不发布投入。
- 全部正向credits保持UNALLOCATED，不称为盈利或费用。

## 尚未通过的部分

初始未锚定翻前以及第二手翻前未建立自动初值；部分街中字段拒识使候选中断。
条件分区不证明所有AA规则语义，仍canonical_verified=false；没有向策略开放。
这是自动基线与运行金额的真实进展，不是整套视觉验收通过。

7项测试通过、flake8通过：自动上下文、单次加款、初始未锚定拒绝、模态/收筹
失效、历史动作不能被遗忘、确认延迟时不公开旧账、credits只保留一次。

## 后续街道与币标修复后的联合回归

`aa8_causal_wagers_v2_dev_v3`的3839帧中1978帧候选、1861帧UNKNOWN，
6组自动初值、16次金额状态变化。第二手翻前3380–3381现在建立price4初值。
这仍是开发覆盖率，不能当成准确率或整个视觉系统通过。

4402/4403实际都有行动者3，不需要放宽行动者门槛。街道改用正向ROI几何独立于
牌点身份，4405的38正确属于flop；两手21+17标记比较现另检查街道，错配为0。
但该次翻牌初值仍失败：中央原始文本114的4分数0.8728，低于0.9，因此金额
保持UNKNOWN，不能根据标题114反填。该街后续下注不发布。

初值可缓存新街第一帧正向几何，第二帧确认后才允许发布；仍要求当前行动者、
完整金额分区和无先行动作。另加单调保护，河牌动画暂少两张不能重新初始化
成flop。这个保护在完整回放之后单测追加，根任务整合时需跑最终完整回归。
当前状态适配器、投入适配器与几何三个模块合计29项测试通过，flake8通过。
