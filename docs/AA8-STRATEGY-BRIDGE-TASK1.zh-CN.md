# 策略层任务1：现有能力审核与AA8影子输入桥接

2026-09-09。状态：本任务已完成；策略系统整体尚未完成，未输出实战建议。

## 结论

仓库已有的状态推导、合法动作、主/边池、多人范围、多人权益和策略路由不是
空壳，可以直接复用。缺口位于AA视觉候选与权威`PokerState`之间，以及适合
当前房间规则和完整行动线的策略资产。新增桥接不会把视觉candidate升级成
权威状态，也不会用未知金额、旧状态或单挑近似填补多人输入。

## 本次实现

新增`poker_engine.strategy.aa8_shadow`：

- 固定AA为8个物理座位、Hero4；实际发牌人数参数化为6、7、8；
- 根据已核验庄位和参与者顺时针派生位置；
- 只在手牌边界、牌、底池、余额、本轮投入、整手投入、动作、参与状态、
  庄位和行动线十项均有权威标记时构造`PokerState`和`DecisionContext`；
- 严格核对请求hand/version、8座向量、在局人数、actor、牌面张数及资金守恒；
- 非Hero行动返回WAITING；缺失/冲突返回ABSTAIN；特殊模式返回单独的
  DEFERRED_SPECIAL_MODE；
- 保险、种蘑菇、暴击继续延后，且不会因为未匹配模板就当作普通局；
- 输出只供影子计算，不自动连接桌面建议或执行任何动作。

新增`tools/audit_aa8_strategy_bridge.py`，只读保存的JSONL日志，不读取新录像、
不运行Provider或权益计算。真实开发日志报告位于：
`G:/PokerSense_private/aa8_strategy_bridge_audit_v1/report.json`。

## 现有模块复用审核

| 能力 | 结果 | 当前边界 |
| --- | --- | --- |
| 状态与合法动作 | 复用 | 输入必须是权威PokerState |
| 主池/边池 | 复用 | 依赖每座完整整手投入，不能从当前余额差额猜 |
| 6–8人位置 | 桥接已实现 | 依赖权威庄位和参与者集合 |
| 范围追踪 | 复用 | 需要完整动作历史和版本化先验；当前视觉尚未供应 |
| 多人权益 | 复用 | 支持逐池eligible seats；需要碰撞无效的对手范围 |
| 自适应exact/MC | 复用 | 有本机标定；实时结果仍需影子高精度对账 |
| 路由/Advice/ABSTAIN | 复用 | 缺字段、非Hero或Provider不支持均拒绝 |
| 预翻牌RFI启发式 | 有限复用 | 只覆盖未加注、ante0、rake0；7/8人范围由9人同名位置派生，非GTO |
| HU蓝图 | 不适用当前主线 | 仅单挑，不可拿来近似多人 |
| 翻后完整策略Provider | 未完成 | 现有外部/本地resolver是接口，不是已验证AA策略资产 |
| straddle | 未完成 | 当前GameConfig/行动顺序未编码；不能把2倍BB静默替代straddle |

对于用户描述的3%抽水、前注和可能straddle，现成RFI启发式Provider会因能力
不匹配而返回无策略；测试已钉死这一行为，不能为追求输出绕过Provider门禁。
房间金额仍可配置，但AA实际规则未核验前不授权live策略。
