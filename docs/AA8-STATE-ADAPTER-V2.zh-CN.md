# AA8 V2 连续观察状态适配器（开发候选）

新建`tools/aa8_state_adapter_v2.py`，没有修改冻结V1任何文件。
接口：`AA8StateAdapterV2().observe(frozen_observation_row)`。一个实例只能处理
同一源审计的连续帧；独立录像须新建实例。CLI对每帧源哈希和development角色检查。

## 实现的因果链

- 复用`VisualTimeline`的相邻帧余额和街道证据确认，不复制另一套数字识别。
- 正向牌面完整时推进翻牌/转牌/河牌；未知牌面不清空历史但当前street_candidate
  保持UNKNOWN。清空公共牌本身不会建立新手。
- 正向中心发牌连续两帧可以建立未锚定观察上下文；必须明确不是完整手边界。
- 多座余额减少、中心发牌、零公共牌/零底池、前后稳定可产生新手候选。缺失余额
  仅在当前明确EMPTY/WAITING时排除比较，绝不填0。新手重置上一手waiting/fold状态。
- 参与历史来自明确背牌、弃牌、等待/空座证据；带唯一余额减少和底池增加的
  跟注/加注标记也可支持该座正在参与。保留证据帧，不称为当前画面持续可见。
- 直接复用V1连续确认的动作标记事件，按座位、有限窗口、唯一余额变化与底池
  增量配对；同时多座扣款不分配给单一标记。未配对时保留标记但金额UNKNOWN。
- Aggressive仍是aggressive，不能凭橙色文案假装已分清bet/raise。
- 复用已有无标记短码跟注候选，但不把它伪造为All in文字。
