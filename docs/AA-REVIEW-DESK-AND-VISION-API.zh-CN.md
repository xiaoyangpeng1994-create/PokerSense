# AA 简洁观察台与 DeepSeek 视觉复查

## 操作

- **观察**：默认页面只显示原画面、手牌/公共牌、底池、行动者、最近动作和标记按钮。八座筹码在折叠详情里。动作按最近优先显示。
- **标记此刻**：保存后台处理到的同一帧 JPEG、识别快照及规则版本，观察继续。标记不等于暂停视频，也不保证与浏览器当时的独立预览精确同步。点击“查看刚才标记”打开保存的固定画面。
- **复查记录**：最近30条；选中记录后填写核对范围和纠正内容。人工复查使用版本检查，防止跨页面覆盖；历史修订保留，原始 issue.json 不改写。标正确只代表操作者注明的核对范围。
- **DeepSeek 视觉复查**：在设置中输入 API Key；选中一条记录，勾选发送范围，点击发送。只发送这张冻结截图及其牌面、底池、行动者、各座筹码/投入/字样候选，可能包含截图上的昵称。不会读取当前/后续画面，也不会自动持续上传。
- **设置与分析**：来源、桌规、API设置集中在这里。原手工多人河牌分析与诊断信息在高级折叠区。回到观察页点击开始；设备只在明确选择采集来源并开始后打开。

## API 与数据合同

固定目标 `https://api.deepseek.com/chat/completions`，拒绝重定向。使用图片 base64 和 JSON 输出；默认 `deepseek-flash`，可选官方文档中的兼容名 `deepseek-v4-flash-vision-exp`。实际账户和别名映射以供应商为准。官方参考：[视觉输入](https://api-docs.deepseek.com/zh-cn/guides/vision)、[当前型号说明](https://api-docs.deepseek.com/quick_start/pricing)。

密钥只在服务进程内存，不进入磁盘配置、源码、返回状态或诊断消息；重启后重新填写。清除密钥阻止后续调用，已经发送的请求可能仍会结束。

默认每天20次，操作者可配置1–100次，按UTC日期计数并落盘；失败尝试也计数，重启不重置当日计数。每次最多4MiB图片、2200输出tokens，响应最多128KiB，无自动重试。**次数上限不是费用上限**，服务商实际收费另计。配置不发模型请求。

一次只允许一个网络worker，socket超时25秒，30秒停止等待并拒绝发布晚到结果。计时器不会强制杀死网络线程：底层线程仍收尾时保留busy，防止超时请求不断堆积。断线、模型错误或格式无效均不产生成功结果；不会回退到文字模型猜图，也不返回供应商原始错误正文。

每条模型结果绑定 issue ID、截图SHA、请求模型和prompt版本。AI返回仅包含摘要与match/mismatch/uncertain字段候选；结构不合法或输出截断会拒收。原始观测、人工说明、AI假设分别存储。界面用文本节点显示模型输出，结果轮询不覆盖未保存的人工作答。

人工与AI记录均不自动获得训练、独立验收或策略资格。本轮建立问题积累与复查入口，没有自动重训、自改代码或部署策略。误识别率需要有范围和分母的人工标注；不能从点击问题数量推导总体准确率。
