# RANGE_POSTERIOR_V1：对手河牌范围后验校准

## 结论

**判定：`REJECT`（拒绝把本候选用于改善决策或提升策略资格）。** 候选是可复现的离线诊断实现，但在预先登记的 54 个合成条件世界中，只有 7 项相对冻结 BASELINE V1 提升条件 EV，14 项退化，33 项相等；平均差 **−5.6824 筹码**，最差 **−88.3972 筹码**。总体 log loss、Brier 和强牌概率误差也变差。保留代码、失败行及挑战协议作研究证据，不接入生产建议。

`REAL_HAND_ACCEPTANCE_PENDING=YES`，真实对手校准与盈利均为 `NOT_ASSESSED`。这些世界复用 V1 的公开局面、两位对手每人仅两种底牌的手工支持集，没有独立真实对手群体，也不是完整手牌 bb/100 或 GTO regret。

## 基线调用链与信息边界

当前 AA 离线手工输入进入 `threeway_river_v1.analyze_threeway_river`。河牌起点两份 `RangeDistribution` 是手工、未验证先验；`_Tree` 枚举阻牌相容的联合手牌、按权重归一化。河牌已发生的公开行动通过手工 `ResponseModel` 的合法动作概率更新联合信念，规划器在整个信息集上选择动作。`compile_policy_book` 冻结各公开历史动作；`evaluate_policy_book` 只重放，未知历史按 check-if-free-else-fold 回退。BASELINE V1 的六份策略表和 30 个旧世界保持原字节及源码哈希。

合法的范围更新证据包括**决策前**的公开牌、公开下注/过牌/跟注/弃牌、下注额、行动顺序、可用筹码、当时合法菜单，以及同规则下、按对手和 session 分离的历史公开行动频率。对手底牌只在预测时作为枚举的潜变量；事后摊牌、结算、未来行动不能进入该次预测。历史摊牌可以在严格的过去数据分区中评估或训练，但只取摊牌手会系统性漏掉弃牌且可能偏向强弱极端，不能当作完整范围标签。此仓库目前没有经审计、同规则且覆盖所有决策机会的真实范围校准集。

`RANGE_POSTERIOR_V1` 选择一个可审计的有限贝叶斯过滤器作首个候选。输入明确是**转牌公开行动发生前**的手工组合权重、单独的 `PreActionRangeBinding` 阶段/来源声明、两名对手各一条转牌公开 `pressure/passive` 事件、当时四张公开牌、事件来源哈希与先后序号，以及一个 `manual_unvalidated` 行动似然表。挑战为了固定与 V1 相同的数字先验，**把 V1 手工范围的数值复制并重新声明为合成转牌行动前先验**；这不是对其历史来源的事实认定，真实河牌起点先验未经阶段核对不得再条件化该行动。每个对手的有限支持集中，按该转牌可见的 6 张牌牌力把最高等级标为 `strong`，其余为 `weak`；固定主观似然为 `P(pressure|strong)=3/4`、`P(pressure|weak)=1/4`。逐组合乘似然，输出仍标 `manual_river_start_assumption`，置信度和有效样本数均为零。原有河牌历史由规划器随后**只条件化一次**。公开事件须早于 Hero 河牌决策，board 必须为当前河牌的前四张，输入类型没有真实隐藏底牌字段；超出约定范围即拒绝。哈希、阶段声明和序号是来源约束，不能自行证明真实采集可信。

没有选择频率拟合、玩家风格层级先验、分类器或 Jev：这些需要可审计的机会分母、规则/玩家身份绑定和分 session 的独立验证。当前主观似然不能从旧 30 世界反推“最佳”参数，Jev 也没有调用或被赋予真值地位。研究依据包括 [Bayes' Bluff](https://dl.acm.org/doi/10.5555/3020336.3020403) 对策略后验与响应的区分、[Using Bayesian Networks to Model a Poker Player](https://cdn.aaai.org/ocs/ws/ws1085/7160-30514-1-PB.pdf) 对未摊牌隐变量和摊牌选择偏差的讨论，以及[公开信念和行动条件范围的教学综述](https://www.alankuhnle.com/teaching/f25-631/lecture-slides/m8-opponent-modeling/opp-model.pdf)。它们提供建模思路，不是 AA 桌规或本候选似然的实证背书。

## 先冻结挑战，再实现候选

基线为合并 `main` `af67b4bb3ba56da2d4fdb70e0731583afc7aaf40`；V1 基线文件 SHA256 `3b9983b46c054a40499286467164c68e2e1ea7039df0a5c2470859ebd702eab4`，旧结果摘要 `c1a725f3f95a76261fb041af200e45bae02b6836202b36ec56578f0afd680aae`。先单独提交挑战协议 `1c23d0b50e008910c02ef1f9f1ab34a576d4ca2d`，文件 SHA256 `073676f61d9f230c060ba0de4f147cb6f7a80387a86cb670acf9f12605f99904`；此时尚无候选代码。随后实现固定 `3/4,1/4` 候选并一次性运行挑战，没有按结果调参。挑战协议对作者可见，且复用旧局面与组合支持，因此是**时间顺序上预先登记的合成压力测试**，不是盲法或独立实证 holdout。

挑战全交叉：6 个 V1 公开局面 × 3 种转牌公开行动模式（双强势、分歧、双被动）× 3 种预先指定的真实行动生成机制（强牌更常强势 `4/5,1/5`、无信息 `1/2,1/2`、反向 `1/5,4/5`），共 54 项。真实机制只交给独立的评估世界构造；候选函数只接收公开事件及固定主观似然。同一局面和事件模式只编译**一份**候选策略表，跨 3 个真实机制重放。两方使用完全相同的 `threeway_policy_evaluation_v1.evaluate_policy_book`、世界哈希与 V1 预算（联合组合 128、节点 20000）；未完成行仍在 54 的分母。旧 30 世界仅做 V1 原样自检和开发回归，不作泛化证据。

54/54 固定评估完成、54/54 两方回退概率为零；根动作不一致 21 项。已知机制时同一内核重规划所得的**模型知识差**：强牌机制 V1 平均 16.3999 → 候选 0.9316 筹码，无信息 0 → 6.9323，反向 16.7248 → 42.3079。此量共用规划器结算内核，是诊断性的条件损失，**不是 GTO regret**。log loss/Brier 是在合成真值分布上对两种组合做期望评分，不是 54 次实战摊牌频率校准。三个机制的结果构成模型不确定性包络；没有独立 session 样本，不能给有统计含义的置信区间。

本候选在行动确实偏向强牌时有用，却无法仅从一次公开动作识别行动与牌力关联的方向；无信息时 V1 原手工范围恰好更可靠，反向时错误过滤造成最大退化。把较尖锐的后验直接编进策略会放大这类似然误设。平均值只是等权三个**人为**机制的压力测试描述，不是现实对手分布的期望收益。因此 `REJECT` 是对当前固定似然候选的决策用途判定，并不证明人工范围永远正确或贝叶斯/学习方法无效。
