# AA8 特殊模式：字面证据与资金隔离

2026-09-09。实现 `tools/aa8_special_modes.py`，仅处理已有开发录像。

## 本轮实现

- 498×1080 八座归一化帧的独立特殊标记读取器；不产生扑克下注动作。
- 从第二手 4824 帧提取保险模式提示与“购买剩余”固定文字；
  从 4890 帧提取第 3 座“投保6”、“蘑菇:3BB”、“暴击:7BB”字面模板。
- 模板匹配使用固定 .96 阈值，返回逐项分数和正证据。未匹配为未知，
  不表示该模式关闭。浮层和按钮遮住规则文字时不强行补值。
- 保险标签不作为跟注、加注或资金已经扣除的证明。保险本金、保费、
  赔付与牌局底池分开；只有外部已经核实、唯一编号的资金流水证据
  才能填入分类账。6 或 13 的未知差额不会自动标成种蘑菇或抽水。
- 种蘑菇与暴击规则文字不等于实际触发；两项触发结果保持 UNKNOWN。
  本录像没有鱿鱼游戏证据，因此不把种蘑菇映射成鱿鱼。

## 尚未满足的验收

这是同一开发录像的字面模板，不是通用中文 OCR 或独立验收准确率。
投保识别当前只覆盖第 3 座且具体文字为投保6；不能外推任意座位/数值。
尚未自动核实种蘑菇或暴击触发、保险现金流水、抽水规则与独立特殊模式样本。
本模块不能独立解除视觉验收或策略就绪阻断。
