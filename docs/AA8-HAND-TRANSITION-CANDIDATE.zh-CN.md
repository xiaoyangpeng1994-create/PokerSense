# AA8 自动新手边界候选

2026-09-09。自动候选已真实运行；不替代人工源帧登记，也不是完整换手验收。

`tools/aa8_hand_transition.py` 接受连续金额/board_count 观察与当前图片。
首开发手1263的中央发牌背面作为唯一图像模板，固定中央矩形红色与白边
两项均需通过0.90门槛。无正证据输出UNKNOWN，不以低分宣称“肯定没有发牌”。

时序器要求相邻帧、之前至少两帧稳定完整余额、零公共牌/零底池，随后至少
三个座位同时减少余额并出现中央发牌牌背，新余额与发牌画面再持续两帧确认。
不输入手牌边界fixture、参考动作、赢钱结论，不按已知帧号触发。输出始终
NEW_HAND_CANDIDATE、authoritative_boundary=false，外部必须保留候选性质。

逐帧图片复用现有开发PNG并校验源SHA，无重新解码或录制。
