## 状态与资产合同

`aa_public_features_v2` 返回可检查的 `exact_key / abstract_key / exact_view /
features / abstraction_disclosure`。精确视图保留个人牌、逐街公共牌、公开历史、
筹码／投入、合法菜单及短加注重开状态；金额只规范文本写法，不做数值分桶。
只对牌序无关部分和整局一致的花色置换作等价规范化。物理座位保留，未声称
已经证明席位相对化等价。

学习特征明确有损，包含牌型、本人／公共牌贡献、听牌和阻断关系等。不同精确
状态可以得到同一学习键，但该碰撞不宣称策略等价、校准 equity 或 GTO。
测试必须区分同一牌面上的坚果同花听牌与无该听牌，保留逐街到达路径，并验证
全局花色置换一致。V1 编码与原资产保留，V2 使用独立资产类型和版本拒绝错配。

两版冻结策略均要求64字符小写十六进制 `for_game` salt，独立于发牌 seed。
影子执行器按资产版本使用同一编码器，仍只接受明确的模拟环境输入；没有新的
实时 Advice 注册、打包或界面。

### 冻结概率验证合同

V1/V2 loader 与 `AAIsolatedPolicyWorker` 共用 `validate_distribution`：
每个分布的菜单必须非空，动作 ID 是唯一、非空字符串，键与所声明菜单完全匹配。
概率仅接受原生 `int/float`（不接受 bool），必须有限且各自在 `[0,1]` 内。
质量定义为 `math.fsum` 的稳定求和，要求 `abs(mass - 1) <= 1e-12`，
明确 `rel_tol=0`；边缘按实际二进制浮点值判断，不把十进制拼写当精确质量。
不归一化、不裁剪或补入概率。worker 在 JSON 复制前验证，避免非法键被转换为字符串。
空策略表仍表示没有覆盖；空单个分布拒绝。generic worker 的字符串动作不代替
V2 动作语法或查询时的合法菜单验证；范围、合法动作、时间及实时拒答门槛保持原样。

这是有意收紧 loader：此前约 `1e-9` 质量容差内、但超过 worker `1e-12` 的
V1/V2 工件现在在加载时拒绝；单项超 1 或非法动作 ID 也拒绝。摘要正确不代表
概率合法，不能通过重写摘要或静默修复继续使用这些分布。正常 onehot、均匀和已有
`average_policy` 导出形式不变，工件 schema、摘要算法、编码器与训练算法不变。
本轮公开合成 6/7/8 人 check-call 路径的 18 工件／504 分布兼容探针通过，
不是全部历史私有工件的验收；没有下载私有包或运行训练。

本接口修复不补平均策略键，不解释原有信息集缺失拒答，也不提高覆盖或策略资格。
shadow 编码一致性、deadline 与采样语义作为后续独立范围，不在本补丁中修改。

## 训练前冻结

`tools/aa_policy_readiness_study.py freeze` 在拟合前固定：

- V1_FIXED 与 V2 各6/7/8人×种子1103/2207/3301，共18个训练配置。
- 初始100BB；模拟规则原样记录，不宣称是真实 AA 费用。
- 每配置最大60秒，包含本配置检查、拟合、checkpoint 和保存。预留
  `min(5秒,20%slot)` 完成最终序列化；两版同样约束。
- 每配置1000000节点／100000信息集容量，每轮最大深度256，请求轮数仅是上限；
  预算耗尽不算策略质量失败。完整更新与被丢弃的部分更新分别记录。
- 另有18个不更新 regret 的实际对照，各固定2轮／最多5秒；它验证更新机制，
  不是与60秒候选等资源的收益或性能比较。
- 评估6,000,000–6,000,029，查询5,000,000–5,000,004，训练域≥2^62。
  四百万区间留作后续确认。旧一百万、早期三百万协议和3,100,000–3,100,004
  工程查询归入开发／退役区间；测试只用明确开发种子。
- 所有项目 `src`／`tools` Python 文件、pyproject、Python 与 PokerKit 依赖字节
  固定哈希。源码／依赖漂移拒绝继续，不刷新旧 manifest 掩盖变化。

## 运行与总预算

```powershell
$env:PYTHONPATH='src'; $env:PYTHONUTF8='1'
python -m tools.aa_policy_readiness_study freeze --output <全新目录>
python -m tools.aa_policy_readiness_study train --output <同一目录> --batch-seconds 2400
python -m tools.aa_policy_readiness_study report --output <同一目录>
```

只有 Gate2 全部通过后，才运行 `evaluate --output <同一目录> --batch-seconds 2400`。
每次命令外层实际进程监督最多允许3600秒，包含初始化、拟合、评估与保存；
Windows 用自有 Job Object 终止自身子进程树。未完成任务留在分母，并从最后完整
checkpoint／原子种子分片恢复；不会给被中断的训练重新发一份60秒预算。
不要并发运行同一研究目录。默认运行不花钱、不联网推理、不读取真实媒体或开设备。

## 三道门槛

1. **评估链**：实际冻结资产加载、独立 salt、完整对局、失败分类与完整分母，
   正控轨迹／终局／收益与直接策略一致。由 Stage1 修复及独立复现验收。
2. **学习信号**：从绑定 checkpoint 恢复状态、核对真实导出平均策略，重新计算
   至少两轮完整更新和重复访问状态上的非均匀分布（TV>1e-8）。九个V2配置必须
   全部满足；不更新对照必须保持均匀。不信任报告中的自报 `learning_signal`。
3. **新牌局可执行性**：按每个人数／训练种子，完整牌局完成率≥80%，并有四街
   有效查询正例、零非法动作和声明的隐藏信息探针通过。仍不代表策略强度或实战资格。

完整研究保留11340个配对机会（两版、全部位置和三类固定脚本对手），查询另有
3150个机会，不能混入收益分母。未知信息集不会用弃牌、均匀随机或启发式填洞。
拒答后未知的街道后缀不计作命中或未命中；缺失、失败、未执行与成功分别报告。
包含阻断的组不从完成子集得出整体EV。

查询是预定脚本形成的合法前缀，不是候选自行打出的轨迹：普通四街、合法非网格
加注、全下价格、不同初始码量边池。最后一类故意超出等100BB资产范围，必须拒绝；
它不能被包装成已支持边池策略或计入覆盖正例。actor/street完整序列在训练前用
开发种子4441/4442冻结，删除后缀再重算汇总也不能通过。

本地策略调用耗时仅报告调用本身，不能替代物理采集卡到浏览器的p95/p99。
Gate2 不通过就不使用新评估集；Gate3 不通过就保留结果停止本轮，不自动换算法、
追加样本或购买云算力。全部结果仍 `research_only` / `NOT_ASSESSED`。
